      label={"HTTP: Bearer Auth"}
      value={"backchannelBearer"}
    >


      Backchannel OIDC bearer token. Every route family asks for its own scopes: nauthilus:authenticate for the authentication endpoints and these OpenAPI documents, nauthilus:security_read for brute-force and OIDC session listings, nauthilus:security_write for cache and brute-force flushes and OIDC session deletion (either of them for the status of an asynchronous job), the MFA and WebAuthn scopes for the MFA backchannel, and the support scopes for /api/v1/support. nauthilus:security includes both security scopes, and nauthilus:admin is accepted on the security and MFA routes as well; neither opens the authentication endpoints or the support routes.
