Recorded OIDC authorization-code completion of one flow. Nauthilus's part ends with the token response for the flow's code (state tokens_issued); a relying-party session after it is never observed. Only authorization-code flows carry this block; SAML, device-code, flows without grant evidence, and latched flows (decided by the latch) have none.
